# Support

For setup problems, start with [installation and troubleshooting](docs/INSTALLATION.md#troubleshooting). For mechanics and controls, use the [player guide](docs/PLAYER_GUIDE.md).

Report reproducible bugs or propose features through [GitHub Issues](https://github.com/OuterRingFoundry/SporeAddition/issues/new/choose). Include exact versions and reproduction steps. Attach `logs/latest.log` or the relevant crash report after removing private details.

Only the dependency combinations listed in [compatibility](compatibility/README.md) have recorded validation. A successful CI run does not guarantee every modpack combination or long-duration server workload.

Downloads are published under [GitHub Releases](https://github.com/OuterRingFoundry/SporeAddition/releases). Use the JAR and its matching checksum, rather than the source-code archive.
