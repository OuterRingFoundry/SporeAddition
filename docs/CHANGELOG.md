# 0.2.0-dev

- Rift Cairn ritual: reusable talisman, one pearl per survival entry, free recall,
  personal return position, shared arrival cairn and an empty-handed escape route.
- Dedicated folded terrain with Drowned Hollows, Blighted Wilds, Ribbed Highlands
  and intact Remnant Groves; occasional calcite ribs and luminous tips.
- Regional corruption relative to each dimension's saved index, displayed in the
  HUD and applied to local combat strength and grove spawning.
- One starting Hive Mind. Dimension caps: 1 at 5, 2 at 6, 3 at 7, unlimited at 8+.
  Unloaded hives remain counted, and old saves receive an entity census.
- Optional Civillis territory notices for corrupted, overrun, threatened, purged,
  remnant and mushroom-sanctuary areas, retaining native labels and HUD settings.
- Retains default interdimensional quarantine, Overworld mushroom protection,
  Spore structure isolation, OP controls, and ConcentricWorld compatibility.

Use matching 0.2.0-dev addon versions on server and clients. Terrain changes affect
new chunks. Spore 2.2.0j and NeoForge 21.1.249 for Minecraft 1.21.1 are required.
